CAT PORTFOLIO 2.0 — PHASE 2

Files:
- index.html
- css/style.css
- js/main.js

Deploy:
1. Download and extract the ZIP.
2. Copy index.html, css/, and js/ into the root of your GitHub Pages repository.
3. Commit and push to the branch/folder configured for GitHub Pages.
4. Open the published site and test desktop + mobile.

Before publishing:
- Replace the Instagram and TikTok href="#" placeholders in index.html with your real profile URLs.
- Replace the CSS placeholder artwork in the project cards with your own project images in Phase 2.
- Optional music: add an audio file you are authorized to use at assets/music/gods-menu.mp3. Otherwise remove the audio element or leave it unavailable.
- The Swirls resource links currently point to #contact placeholders until the real project files/URLs are supplied.
- Review your public contact details before publishing.

The intro appears once per browser tab session and has both Enter and Skip controls.
Theme defaults to dark. The visitor's light/dark choice is saved in localStorage.
No framework or build step is required.
